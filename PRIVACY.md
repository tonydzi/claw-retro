# Privacy policy: claw-retro

Last updated: 16 November 2026.

This plugin is instructions only. It contains Markdown and JSON files and an icon,
runs no code of its own, and collects and sends no data. There is no hosted service.

When you run the skill, your agent reads and writes files in your own workspace
(for example git history, your rules file and a retro note) using the tools your
client already provides. Anything the agent processes is handled under your client's
and model provider's own settings and privacy policies.
